
# Restaurant Invoice Viewer MVP

גרסה ראשונה למערכת חשבוניות למסעדה.

## מה היא עושה
- העלאת PDF או תמונה
- הצגת החשבונית כתמונה מלאה
- מעבר בין עמודים ב-PDF
- חילוץ נתונים בסיסיים
- תיקון ידני
- בדיקת סכומים
- שמירה בארכיון מקומי

## התקנה

פתח Terminal בתיקייה שחילצת והריץ:

```bash
source ~/restaurant-invoices/.venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

אחרי ההרצה ייפתח הדפדפן.
